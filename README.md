# Import Data using Transform Maps (Spreadsheet)

## Project Overview

This project demonstrates how to import data from a spreadsheet into ServiceNow using Import Sets and Transform Maps.

## Objective

The main objective of this project is to import spreadsheet data into a ServiceNow table and transform the imported data into the required target fields.

## Technologies Used

- ServiceNow
- Import Sets
- Transform Maps
- Spreadsheet / CSV
- GitHub

## Project Phases

1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development
6. Project Testing
7. Project Documentation
8. Project Demonstration

## Expected Result

Spreadsheet data should be successfully imported into the selected ServiceNow target table using a Transform Map.
